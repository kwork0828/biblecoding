# video/ 작업 규칙

## 작업이 끝날 때마다 하는 보고 (필수)
매 응답의 마지막에 아래 순서로 보고한다. 초보자도 한눈에 이해되도록 쉬운 말로 쓴다.

1. **한 줄 결론**: 지금 무엇이 되고 무엇이 안 되는지
2. **한 일**: 개조식, 3~7줄
3. **현재 상태**: 개조식. 완료 / 막힘 / 대기를 구분
4. **다이어그램**: 전체 흐름에서 지금 위치를 텍스트 도식으로 표시
5. **이미지**: 같은 내용을 PNG 한 장으로 만들어 첨부 (`video/status/status_YYYYMMDD.png`, 1600x900)
6. **다음 행동**: 사용자가 바로 할 수 있는 것 1~3개

## 영상 제작 규칙
- 앱 소스는 수정하지 않는다. 산출물은 video/ 안에만 만든다.
- 기록에 없는 내용은 [확인 필요]로 표시한다.
- 영상을 만들면 pycapcut으로 캡컷 드래프트도 함께 만든다. 빌드 성공은 검증이 아니다. 검증은 사용자가 캡컷에서 직접 재생해서 한다.
